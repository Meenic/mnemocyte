Memory for TypeScript AI apps.

Save what your AI app learns, then pull back what matters when you build a prompt.

$pnpm add mnemocyte
Get started →

Save once. Recall as a prompt.

add stores what your app learns about a user. context returns the relevant memories as Markdown, ready for a system prompt.

import { createMemory } from "mnemocyte";
import { openaiEmbedder } from "mnemocyte/embedders";

const memory = createMemory({
  namespace: "my-app",
  embedder: openaiEmbedder({
    model: "text-embedding-3-small",
  }),
});

const user = memory.for({ entityId: "user_123" });

await user.add({
  content: "Prefers short, direct answers.",
});

const context = await user.context({
  query: "How should I reply?",
});

context returns

# Memory Context

## Relevant Memories

- kind=preference; importance=normal; score=0.464
  Prefers short, direct answers.

Every memory has a life cycle.

From the first save to the last prune, each step is one call you control.

Add

Save what your app learns. Give a memory a key and later saves update it in place.

Recall

Hybrid search ranks by meaning and keywords, with newer and more important memories nudged up.

Merge

findDuplicates spots near-identical memories and consolidate folds them into one.

Prune

Expire memories, prune what nobody used, or erase a user in one call.

Getting started

From an empty folder to memories in a prompt: install Mnemocyte, start Postgres, write memory.ts, create the schema, then store and recall.

  • Node.js22.18 or newer
  • Postgres with pgvector0.8.0 or newer
  • An embedderOpenAI key or local Ollama

Create the project

mkdir my-agent && cd my-agent
pnpm init
pnpm pkg set type=module
pnpm add mnemocyte postgres
pnpm add -D typescript @types/node

Node 22.18 runs .ts files directly, so there is no build step.

Start Postgres

docker run -d --name mnemocyte-db -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 pgvector/pgvector:0.8.7-pg18

Any Postgres with pgvector 0.8.0 or later works, including Neon, Supabase and RDS. Put its URL and your OPENAI_API_KEY in .env.

Write memory.ts

Create the client once and share it across your app and scripts.

import { createMemory } from "mnemocyte";
import { openaiEmbedder } from "mnemocyte/embedders";
import postgres from "postgres";

export const sql = postgres(process.env.DATABASE_URL!);

export const memory = createMemory({
  namespace: "my-agent",
  store: sql,
  embedder: openaiEmbedder({ model: "text-embedding-3-small" }),
});

pnpm exec mnemocyte init can write this file for you, for postgres.js, node-postgres, Drizzle or PGlite.

Create the schema

Mnemocyte never creates tables on its own. Run migrate on every deploy; it applies only what is missing.

pnpm exec mnemocyte migrate

Store and recall

Bind a client to one user with memory.for, save what you learn, and render the best matches for your prompt.

const user = memory.for({ entityId: session.userId });

await user.add({
  key: "style",
  kind: "preference",
  content: "Prefers short, direct answers without small talk.",
});

const context = await user.context({ query: message, maxTokens: 800 });

No database yet? Leave out store and memories live in process memory until it exits. Moving to Postgres later uses the same calls.

Changelog

Every release, newest first. Since 1.0 the documented API follows semantic versioning, so breaking changes wait for 2.0.

1.2.016 November 2026

Search language, own schema, drizzle-kit

  • Pick the keyword search language with --text-search-config. simple suits memories in several languages.
  • postgresStore({ client, schemaName }) keeps every Mnemocyte table in a schema of its own.
  • mnemocyte generate --adapter drizzle lets drizzle-kit manage the tables with the rest of your schema.
  • No migration: 1.1 and 1.2 clients share an installation.
1.1.016 November 2026

More control, more visibility

  • experimental.contextWithMemories returns the memories behind the prompt text, for citations.
  • createdBefore and createdAfter on list and context.
  • delete returns what it changed, and listAuditLog({ memoryId }) shows one memory’s history.
  • --json on check and migrate --dry-run, plus headers and fetch on every HTTP embedder.
1.0.115 November 2026

Hints that work with pnpm

  • mnemocyte init now ends with the runner your project uses, such as pnpm exec mnemocyte migrate.
1.0.015 November 2026

First stable release

  • The API in the guides now follows semantic versioning.
  • The README and guides were rewritten for first-time users.
